# 🌱 주문 관리 (부모님과 공유, 구글 로그인 없이 PIN 으로)

구글 시트는 **나만 볼 수 있게 잠그고**, 부모님은 **웹앱 주소 + PIN** 으로만 들어오는 방식입니다.
데이터는 구글 시트 밖으로 나가지 않습니다(GitHub 등에 올라가지 않음).

```
부모님 휴대폰 ──(웹앱 주소 + PIN)──▶ Apps Script 웹앱 ──(내 권한)──▶ 내 구글 시트 (비공개)
```

## 어떻게 지켜지나
| 위험 | 막는 방법 |
| --- | --- |
| 시트 링크가 퍼짐 | 시트 공유를 "제한됨"으로 바꿔서 **링크만으로는 아무도 못 봄** |
| 웹앱 주소가 퍼짐 | 주소만으로는 안 열리고 **사람마다 다른 PIN** 이 있어야 함 |
| PIN 을 마구 눌러 보기 | **5번 틀리면 15분 잠금** + 내 메일로 알림 |
| 휴대폰 화면을 누가 봄 / 캡처 | 이름·전화·주소는 **김\*수, 010-\*\*\*\*-1234** 처럼 가려서 보여 주고, "보기"를 눌러야 1분간 보임 |
| 누가 언제 개인정보를 봤는지 | 로그인·보기·수정이 숨김 시트 `_접속기록` 에 남음 |
| 휴대폰 분실 | 시트 메뉴 **모든 기기 로그아웃** 또는 그 사람 PIN 바꾸기 |
| 오래된 개인정보 | 주문일 180일 지난 행의 개인정보를 **자동 파기**(선택, 기간 조정 가능) |
| 코드 유출 | PIN 은 코드에 없음(해시로만 저장). 수식 입력(`=IMPORTXML` 등)으로 데이터 빼가기 차단 |

## 설치 (PC 에서 10분, 한 번만)

### 1. 시트 잠그기 — 가장 중요
1. 시트 오른쪽 위 **공유** → "일반 액세스"를 **제한됨** 으로 바꾸고, 부모님 계정 등 필요 없는 사람은 빼기
2. 메뉴 **파일 → 공유 → 웹에 게시** 가 켜져 있으면 **게시 중지**
   (지금 쓰시는 `.../htmlview` 주소가 로그인 없이 열린다면, 시트가 "링크가 있는 모든 사용자"나 "웹에 게시" 상태라는 뜻입니다)

### 2. 코드 넣기
1. 시트에서 **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs` 내용을 모두 지우고 이 폴더의 [`Code.gs`](Code.gs) 를 붙여 넣기
3. 왼쪽 **＋ → HTML** → 이름을 `Index` 로 만들고 [`Index.html`](Index.html) 내용을 붙여 넣기
4. 💾 저장
5. `Code.gs` 맨 위 `CONFIG` 에서 필요하면 조정
   - `HEADER_ROW`: 열 이름이 2행에 있으면 `2`
   - `SHEETS`: 특정 시트만 보이게 하려면 `['주문', '11월']` 처럼
   - `ANONYMIZE_AFTER_DAYS`: 개인정보 파기 기간 (교환·반품·재구매 확인 기간을 생각해서 정하세요)

### 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
2. **다음 사용자 인증 정보로 실행: 나**
3. **액세스 권한이 있는 사용자: 모든 사용자** (← "Google 계정이 있는 모든 사용자" 아님. 그래야 부모님이 로그인 없이 씀)
4. 배포 → 권한 허용(내 계정 → "고급" → 이동 → 허용) → **웹 앱 URL** 복사

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영되고, 주소는 그대로 유지됩니다.

### 4. PIN 만들기
1. 시트를 새로고침하면 메뉴에 **🔐 주문관리** 가 생깁니다
2. **사용자 추가 / PIN 바꾸기** → 이름(아버지) → PIN(숫자 6~12자리) → 권한
   - 나: `1 관리자`, 부모님: `2 편집`(체크·수정·추가 가능) 또는 `3 보기만`
3. 어머니, 나 도 같은 방법으로. **PIN 은 말로 알려 드리고 카톡·문자에 남기지 마세요.**

### 5. 부모님 휴대폰에 설치
1. 웹앱 URL 을 부모님 휴대폰에서 열기 (이 주소도 가족 단톡방 같은 데 올리지 말고 직접 넣어 드리기)
2. PIN 입력, "이 휴대폰에서 로그인 유지" 체크 (30일 유지)
3. 홈 화면에 추가: 아이폰 Safari 공유 → 홈 화면에 추가 / 안드로이드 Chrome ⋮ → 홈 화면에 추가

## 쓰는 법
- 시트의 열 이름을 읽어서 화면이 **자동으로** 만들어집니다. 열을 추가·변경해도 코드를 고칠 필요가 없어요.
- 체크박스 열(예: 입금, 발송)은 큰 버튼으로 나오고, 누르면 바로 시트에 체크됩니다.
  **마지막 체크박스 열**이 체크되면 "끝난 것" 으로 봅니다.
- 다른 칸은 눌러서 고칠 수 있고, 아래 **＋ 새 주문** 으로 행을 추가합니다.
- 두 사람이 같은 칸을 동시에 고치면 나중 사람에게 "그사이 다른 분이 바꿨어요" 가 뜨고 새로 불러옵니다.
- 위 🔒 를 누르면 이 기기에서 로그아웃.
- 수식이 들어 있는 칸은 웹앱에서 고칠 수 없습니다(시트에서 직접).

## 알아 둘 점
- 처음 열면 맨 위에 "이 애플리케이션은 다른 사용자가 만들었습니다" 라는 구글 안내 문구가 보입니다. 정상입니다.
- 아이폰은 사이트 데이터를 7일쯤 안 쓰면 지우기도 해서, 가끔 PIN 을 다시 물을 수 있어요.
- PIN 이 웹앱 주소를 대신하는 열쇠이므로 6자리 이상, 사람마다 다르게.
- 네이버 스마트스토어의 고객 개인정보는 배송 목적으로만 쓰고, 목적이 끝나면 파기하는 것이 원칙입니다. 자동 파기 기능을 켜 두는 것을 권합니다(🔐 주문관리 → 개인정보 자동 파기 켜기).
