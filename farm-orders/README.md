# 🌱 주문 관리 (부모님과 공유, 구글 로그인 없이 PIN 으로)

구글 시트는 **나만 볼 수 있게 잠그고**, 부모님은 **웹앱 주소 + PIN** 으로만 들어오는 방식입니다.
데이터는 구글 시트 밖으로 나가지 않습니다(GitHub 등에 올라가지 않음).

```
부모님 휴대폰 ──(웹앱 주소 + PIN)──▶ Apps Script 웹앱 ──(내 권한)──▶ 내 구글 시트 (비공개)
```

## 이 시트에 맞춘 설정
열: `순번 · 주문번호 · 구분 · 용량 · 비고 · 구매자명 · 수취인명 · 주문일 · 택배사 · 송장번호 · 발송일 · 수취인연락처1 · 통합배송지 · 배송메모 · 우편번호 · 수익금(-수수료) · 인삼대금 · 순수익 · 정산여부`

| 열 | 웹앱에서 |
| --- | --- |
| 구분 · 용량 · 주문일 | 주문 카드 제목 |
| 구매자명 · 수취인명 · 수취인연락처1 · 통합배송지 · 우편번호 | 개인정보: `김*희` `010-****-5678` `경기도 이천시 ***` 처럼 가림, "보기" 누르면 1분간 보임(기록 남음) |
| 배송메모 | 그대로 보이되, 안에 섞인 전화번호는 가림 |
| 택배사 · 송장번호 · 발송일 | **📦 발송 처리** 버튼 한 번으로 채움 (택배사는 최근 값 자동, 발송일은 오늘). 송장번호나 발송일이 있으면 "발송 완료" |
| 정산여부 | `O`(또는 `완료`·체크) 면 "정산 완료". 버튼으로 표시/취소 (`O` 를 넣음) |
| 순번 · 주문번호 | 웹앱에서 못 고침. 새 주문 추가 시 순번은 자동으로 다음 번호 |
| 순번 · 주문번호 · 구매자명 · 우편번호 · 수익금 · 인삼대금 · 순수익 | 카드의 "자세히 ▾" 안에 접혀 있음 |

> 수익금·순수익을 부모님께 **아예 안 보이게** 하려면 `Code.gs` 의 `ADMIN_ONLY_KEYWORDS: ['수익금', '순수익']` 로 바꾸세요. 서버에서부터 안 보냅니다.

## 📊 월별 정산 · 🧾 계산서
**웹앱 📊 월별 합계** (관리자·부모님 모두)
- 달마다 수익금·인삼대금·순수익, 발송 완료/남은 건수, **정산완료 / 미정산 인삼대금**
- **🧾 계산서·정산 내역 보기**: 과세(세금계산서) 공급가액·세액·합계, 면세(계산서) 금액, 품목별 건수·금액, 그달 주문 목록(주문일·품목·금액·정산·발송), **📋 계산서용 내용 복사** (홈택스 입력할 때 참고)
- 과세/면세는 `구분` 글자로 나눈 참고값입니다: `홍삼` 이 들어가면 과세, `수삼·건삼·인삼·삼` 이면 면세, 나머지는 "확인 필요". `Code.gs` 의 `TAX_TAXED_KEYWORDS` / `TAX_FREE_KEYWORDS` 로 조정. 금액은 부가세 포함 기준(`TAX_VAT_INCLUDED`). **발행 전 세무사·홈택스 기준으로 확인하세요.**

**구글 시트 `월별정산` · `정산내역`** (관리자)
- 시트 메뉴 **🔐 주문관리 → 📊 월별 정산 시트 만들기** → 두 시트가 생기고, 매일 새벽 5시쯤 자동으로 다시 만들어짐. 웹앱 📊 화면의 **정산 시트 갱신** 버튼으로도 즉시 갱신.
- `월별정산`: 월별 한 줄씩 (주문·발송·금액·정산완료/미정산·과세 공급가액/세액·면세·구분별 건수) + 연도 합계
- `정산내역`: 주문별 (월·주문일·순번·주문번호·구분·용량·발송일·택배사·송장번호·금액·과세구분·정산) + 월 소계
- **개인정보는 들어가지 않습니다.** 자동으로 다시 만들어지므로 직접 고치지 마세요.

## 📦 부모님 발송 흐름
1. 부모님이 링크(홈 화면 아이콘)를 열면 **📦 발송 전** 주문부터 보입니다.
2. 발송 전 주문은 택배 보내는 데 필요하므로 **받는 분·연락처·주소(우편번호)·배송메모가 가리지 않고 크게** 보입니다.
   칸마다 **복사**, 연락처 **📞 전화**, **📋 택배 정보 전체 복사**(받는 분/연락처/주소/메모/상품을 한 번에 → 택배 예약 앱에 붙여넣기).
3. 택배를 보낸 뒤 카드 아래 **🚚 보낸 뒤 입력해 주세요** 칸에서 택배사(최근 쓴 곳이 자동 선택, 버튼으로 바꾸기)·**송장번호** 입력 → **✔ 발송 완료 저장**.
   발송일은 오늘로 자동 입력됩니다.
4. 저장하면 그 주문은 "발송 완료" 로 넘어가고, 개인정보는 다시 `김*희` 처럼 가려집니다.

- 관리자 화면에서는 발송 전 주문마다 **🔗 이 주문 링크** 버튼이 있습니다. 누르면 `[주문] 6년근 수삼 750g 발송 부탁드려요 + 링크` 가 복사되어, 카톡으로 부모님께 보내면 **그 주문으로 바로 열립니다** (링크에는 행 번호만 있고 개인정보는 없음. 열려면 PIN·승인된 기기 필요).
- 입력 중인 송장번호는 5분 자동 새로고침에 지워지지 않습니다.
- 발송 전 주문 정보를 본 기록은 하루에 목록이 바뀔 때마다 `_접속기록` 에 남습니다.
- 언제나 가려서 보이게 하려면 `Code.gs` 의 `SHOW_PII_UNSHIPPED: false`.

## 기능
- **📋 주문**: 필터 `전체 / 📦 발송 전 / 발송 완료 / 정산 안 된 것` (건수 표시), 검색(상품, 전화 끝 4자리 등), 칸 눌러서 고치기, ＋ 새 주문
- **📊 월별 합계** (주문일 기준, 시트 전체 행): 달마다 건수, 수익금·인삼대금·순수익 합계, 발송 전 건수, **미정산 건수와 미정산 금액**, 구분별 건수. 맨 위에 올해 합계
- **개인정보 비식별 처리**
  - **자동**: 정산여부 `O` + 발송일(없으면 주문일)로부터 **90일** 지난 주문 → 매일 새벽 처리
  - **바로 (기간 무시)**:
    - 웹앱(관리자만): **🔒 골라서 비식별** → 빨간 안내 줄이 뜨고, **카드를 누르면 ✔ 선택 / 해제** (선택된 카드는 빨간 테두리).
    아래 막대에서 한 번에 고르기: `보이는 주문 전체` · `정산 완료 전부` · `정산 완료 + 90일 지난 것` · `발송 완료 전부` · `모두 해제`.
    카드마다 `발송 완료/전` · `정산 완료/전` · `○일 지남` 표시, 이미 비식별된 주문은 회색으로 고를 수 없음 → **🔒 N건 비식별 처리**
  - 구글 시트: 행 번호를 눌러 줄을 고르고(Shift·Ctrl+클릭으로 여러 줄) **🔐 주문관리 → 비식별: 시트에서 선택한 행만** → 고른 주문 목록을 보여 주고 확인 후 처리
    - 시트 메뉴: "정산 O 주문 전체" 또는 "모든 주문 전체 ⚠️"
  - 처리 결과: 성명 `홍**`, 휴대폰 `010-****-****`, 주소 `경기도 이천시 (비식별)`, 우편번호 `(비식별)`, 배송메모 삭제
  - 숨김 시트 `_비식별기록` 에 처리 시각·주문번호·방식과 **고객키**(휴대폰번호를 비밀키로 HMAC-SHA256 일방향 암호화)가 남습니다.
    원래 번호는 복원할 수 없지만 같은 고객의 재구매인지는 맞춰 볼 수 있습니다.
  - 발송 전·정산 전 주문을 고르면 경고하고, 발송 전이 섞여 있으면 "비식별" 을 직접 입력해야 진행됩니다.

## 🔒 개인정보 암호화 저장 (C1)
시트 메뉴 **🔐 주문관리 → 🔒 개인정보 암호화 켜기** 를 누르면
`구매자명 · 수취인명 · 수취인연락처1 · 통합배송지 · 우편번호 · 배송메모` 가 시트에 **`ENC1:x8f2…` 암호문**으로 저장됩니다.

| | |
| --- | --- |
| 방식 | **AES-256-CTR + HMAC-SHA256** (암호화 후 위조 검사). 같은 이름도 매번 다른 암호문 |
| 열쇠 | 스크립트 속성(시트 주인만 접근)에만 있음. **시트를 복사·내려받기·공유해도 개인정보는 못 읽음** |
| 볼 수 있는 곳 | 웹앱(PIN + 승인된 기기) — 화면은 지금처럼 `김*희` 로 가려 보이고 "보기" 로 풀림 · 시트 메뉴 **선택한 행 개인정보 보기** (시트 주인만, 기록 남음) |
| 새로 들어오는 값 | 웹앱에서 넣거나 고친 값, **시트에 직접 입력·붙여넣기 한 값도 즉시 암호화**. 놓친 것은 매시간 자동 점검 |
| 검색 | 웹앱 검색은 그대로 됨 (전화 끝 4자리 등) |
| 비식별 처리 | 암호문을 풀어서 판단·처리. 비식별된 값(`김**`)은 암호화하지 않고 그대로 둠 |
| 위조·손상 | 암호문이 한 글자라도 바뀌면 `(손상된 암호문)` 으로 표시 (엉뚱한 값을 보여 주지 않음) |
| 되돌리기 | **암호화 끄기** → 모든 암호문을 원래 글자로 |

> ⚠️ **열쇠 백업 필수**: 켠 직후 메뉴 **암호화 열쇠 백업** 으로 열쇠를 비밀번호 관리 앱이나 종이에 적어 두세요(카톡·메일·사진 금지).
> Apps Script 프로젝트를 지우거나 새로 만들면 열쇠가 사라지고, 백업이 없으면 **암호화된 개인정보는 영영 못 풉니다.** 복원은 **암호화 열쇠 복원**.
>
> 알아 둘 점: 시트에서 이름·주소를 직접 볼 수 없게 되므로 택배 송장 출력 등은 웹앱(보기·복사)이나 "선택한 행 개인정보 보기" 를 쓰세요.
> 구글 시트의 버전 기록에는 암호화 전 평문이 남아 있습니다. 옛 버전까지 지우려면 시트를 새 파일로 복사(메뉴 **파일 → 사본 만들기** 후 스크립트·열쇠 이전)하는 방법이 있습니다.

## 📅 날짜 자동 변환
주문일·발송일 칸에 `11/5`, `11.5`, `1105`, `11월 5일`, `26.11.5`, `2026.11.05 13:22`, `오늘`, `어제` 처럼 넣으면
**진짜 날짜로 바꾸고 그 열의 기존 날짜 형식**(가장 많이 쓰인 형식, 없으면 `yyyy-mm-dd`)으로 맞춥니다.
- 웹앱에서 넣을 때도, **시트에서 직접 입력·붙여넣기 할 때도** 자동으로 바뀝니다.
- 연도를 안 쓰면 올해로 보고, 두 달 넘게 미래가 되면 작년으로 봅니다 (1월에 `12/28` → 작년 12월 28일).
- 형식을 정해 두고 싶으면 `Code.gs` 의 `DATE_FORMAT: 'yyyy-mm-dd'` 처럼 적으세요 (예: `'yyyy. m. d'`, `'mm/dd'`).
- 이미 글자로 들어가 있는 예전 날짜는 시트 메뉴 **날짜 칸 형식 한 번에 정리** 로 한 번에 바꿉니다 (월별 합계·90일 계산이 정확해짐).

## 어떻게 지켜지나
| 위험 | 막는 방법 |
| --- | --- |
| 시트 링크가 퍼짐 | 시트 공유를 "제한됨"으로 → **링크만으로는 아무도 못 봄** |
| 웹앱 주소가 퍼짐 | 주소만으로는 안 열리고 **사람마다 다른 PIN** + **승인된 기기** 필요 |
| PIN 이 새어 나감 | 다른 휴대폰에서는 PIN 이 맞아도 **기기 승인** 없이 못 들어옴 + 나에게 메일 |
| 한밤중 접속 시도 | **접속 가능 시간** 밖에는 부모님 계정으로 못 들어옴 |
| PIN 을 마구 눌러 보기 | **5번 틀리면 15분 잠금** + 내 메일로 알림 |
| 휴대폰 화면을 누가 봄 / 캡처 | 개인정보는 가려서 보여 주고 "보기" 1분 뒤 다시 가림. 앱을 내렸다 올리면 다시 가림 |
| 누가 언제 개인정보를 봤는지 | 로그인·보기·수정·발송처리·비식별이 숨김 시트 `_접속기록` 에 남음 |
| 휴대폰 분실 | 시트 메뉴 **모든 기기 로그아웃** 또는 그 사람 PIN 바꾸기 |
| 오래 쌓인 개인정보 | 정산 끝나고 90일 지나면 자동 비식별 |
| 코드 유출 | PIN 은 코드에 없음(해시로만 저장). 수식 입력(`=IMPORTXML` 등)으로 데이터 빼가기 차단 |

## 설치 (PC 에서 10분, 한 번만)

### 1. 시트 잠그기 — 가장 중요
1. 시트 오른쪽 위 **공유** → "일반 액세스"를 **제한됨** 으로, 필요 없는 사람은 빼기
2. **파일 → 공유 → 웹에 게시** 가 켜져 있으면 **게시 중지**

### 2. 코드 넣기
1. 시트에서 **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 모두 지우고 이 폴더의 [`Code.gs`](Code.gs) 붙여 넣기
3. **＋ → HTML** → 이름 `Index` → [`Index.html`](Index.html) 붙여 넣기 → 💾 저장
4. 프로젝트 설정(⚙️) → **시간대: (GMT+09:00) 서울** 확인

### 3. 웹앱으로 배포
1. **배포 → 새 배포** → ⚙️ → **웹 앱**
2. 실행: **나** / 액세스: **모든 사용자** ("Google 계정이 있는 모든 사용자" 아님)
3. 배포 → 권한 허용(고급 → 이동 → 허용) → **웹 앱 URL** 복사

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (주소 그대로 유지)

### 3-1. 주문 시트 양식 만들기 (빈 시트에 설치했을 때)
시트 메뉴 **🔐 주문관리 → 📋 주문 시트 양식 만들기** 를 누르면 클릭 한 번으로:
- 1행 머리글 19개 (`순번 … 정산여부`) + 1행 고정
- 칸 형식: 주문번호·송장번호·연락처·우편번호는 **글자 그대로**(16자리 주문번호가 `2.02E+15` 로, `06236` 이 `6236` 으로 바뀌는 것 방지), 주문일·발송일은 날짜, 금액은 `52,000` 처럼
- 택배사 고르기 목록(CJ대한통운·우체국·한진·롯데·로젠…), 정산여부 고르기 목록(`O`)
- 원하면 예시 주문 3건(가짜 정보, 지워도 됨)

예전 주문을 옮길 때: 원래 시트에서 **2행부터** 복사 → 새 시트 **A2** 클릭 → **Ctrl+Shift+V (값만 붙여넣기)**. 그래야 칸 형식이 유지됩니다.
이미 내용이 있는 시트에서 누르면 새 시트 `주문` 을 만들어 그곳에 양식을 넣습니다.

### 4. PIN 만들기 + 자동 비식별 켜기
1. 시트 새로고침 → 메뉴 **🔐 주문관리** → **사용자 추가 / PIN 바꾸기**
   - 나: `1 관리자` (비식별 처리 버튼은 관리자에게만 보임), 부모님: `2 편집` 또는 `3 보기만`
   - PIN 은 숫자 6~12자리, 사람마다 다르게, **말로** 알려 드리기
2. **🔐 주문관리 → 비식별 자동 처리 켜기 (매일 새벽)**
3. **🔐 주문관리 → 날짜 칸 형식 한 번에 정리** (예전에 글자로 넣은 날짜를 진짜 날짜로)
4. **🔐 주문관리 → 🔒 개인정보 암호화 켜기** → 바로 **암호화 열쇠 백업** 으로 열쇠 보관
5. 내 휴대폰으로 웹앱 열기 → PIN → 승인 대기 → 시트 메뉴 **기기 승인 · 관리** 에서 내 기기 승인
6. 웹앱 ⚙️ 에서 접속 가능 시간·알림 설정 → **설정 저장** (하루 요약 메일 예약도 이때 됨)
7. 처음 한 번은 **비식별: 정산 O + 90일 지난 주문 (지금)** 으로 지난 주문을 정리 (건수 미리 보여 주고 확인 후 진행)

### 5. 부모님 휴대폰에 설치
웹앱 URL 을 직접 열어 드리고 PIN 입력 → "로그인 유지" 체크 → 승인 대기 화면이 뜨면 **내 웹앱 ⚙️ → 기기 관리 → 승인** → 부모님 화면이 자동으로 열림 → 홈 화면에 추가

## 알아 둘 점
- 처음 열면 "이 애플리케이션은 다른 사용자가 만들었습니다" 안내가 보입니다. 정상입니다.
- 비식별 처리는 시트에서 되돌릴 수 없습니다. 실수했으면 **파일 → 버전 기록** 으로 복구하세요.
- 날짜 열이 `2026-11-05`, `2026. 11. 5` 같은 날짜 형식이어야 90일 계산·월별 합계가 됩니다(`11/5` 처럼 연도 없는 글자는 건너뜀).
- 아이폰은 오래 안 쓰면 로그인 유지가 풀려 PIN 을 다시 물을 수 있습니다.
- 기기 확인은 브라우저 저장소를 씁니다. **시크릿/개인 정보 보호 모드**나 카카오톡 안 브라우저에서 열면 매번 새 기기로 보여 승인을 다시 요청할 수 있으니, 기본 브라우저(삼성 인터넷·크롬·사파리)로 홈 화면에 추가해 쓰세요.

## 추가 보안 방안 (선택 — 적용 여부는 직접 결정)
지금 구조의 보안은 결국 **① 내 구글 계정**, **② 웹앱 PIN**, **③ 시트 공유 설정** 세 가지에 달려 있습니다.
아래는 그걸 더 단단히 하는 방법들입니다. ✅ = 설정만 하면 됨, 🛠 = 코드 추가 필요(요청하시면 만들어 드림).

### A. 꼭 권하는 것 (돈·불편 거의 없음)
| # | 방안 | 효과 | 불편 | |
|---|---|---|---|---|
| A1 | **내 구글 계정 2단계 인증 / 패스키** | 시트·웹앱·코드 전부가 이 계정에 달려 있음. 가장 효과 큼 | 거의 없음 | ✅ |
| A2 | 시트 **공유 "제한됨"** + **웹에 게시 중지** + 다른 편집자 없애기 | 링크 유출로 보이는 길 차단 | 없음 | ✅ |
| A3 | 네이버 스마트스토어 **안심번호** 사용 | 시트에 진짜 번호 대신 0504 가상번호만 남음(배송 후 소멸) | 없음 | ✅ |
| A4 | 이 시트를 다른 사람에게 **공유하지 않기**, 부모님 구글 계정도 빼기 | 웹앱 우회 경로 차단 | 없음 | ✅ |

| B2 | **알림 메일** (새 기기·잠김 즉시, 하루 요약, 개인정보 보기 즉시는 선택) | 이상한 접속을 바로 알아챔 | 메일이 옴 | ✅ 적용됨 |

### D. 기타
- **백업**: 구글 시트 버전 기록이 자동 백업 역할. 따로 내려받은 엑셀 파일은 개인정보가 그대로 있으니 PC·카톡에 남기지 않기.
- **할 수 없는 것**: Apps Script 웹앱은 접속자의 IP 를 알 수 없어서 IP 차단·국가 차단은 불가능합니다. 대신 B1(기기 승인)이 그 역할을 합니다.
- **유료(Google Workspace)**: DLP, 접근 조건(기기·위치) 같은 기업용 기능이 있지만 가족 규모에는 과합니다.

**추천 순서**: A1~A4 (오늘 바로) → B1 + B2 → 필요하면 C1.
