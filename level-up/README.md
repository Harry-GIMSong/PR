# 66일 레벨업 ⚔️

E랭크에서 S랭크까지, 66일 동안 일일 퀘스트를 깨며 강해지는 게임형 습관 트래커입니다.
처음엔 쉽게 시작해서 날마다 목표가 조금씩 올라가고, 마지막 날엔 꽤 빡센 양이 됩니다.

## 열기
- `https://harry-gimsong.github.io/PR/level-up/`
- 휴대폰 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있고, 한 번 열어 두면 인터넷 없이도 동작합니다.

## 버전
| | 남자 버전 🗡️ | 여자 버전 🌙 |
|---|---|---|
| 본 퀘스트 | 팔굽혀펴기 10→100회, 윗몸일으키기 10→100회, 스쿼트 20→100회, 달리기 1→10km | 스쿼트 20→150회, 힙 브릿지 15→100회, 플랭크 20초→3분, 걷기·달리기 4,000→12,000보 |
| 서브 퀘스트 | 독서, 명상·호흡, 수면 | 스트레칭, 독서, 수면 |
| 측정의 날 | 팔굽혀펴기 최대, 윗몸일으키기 1분, 1km 기록 | 스쿼트 1분, 플랭크 최대, 푸시업 최대 |

## 규칙
- **랭크**: E(1–7일) · D(8–17) · C(18–30) · B(31–45) · A(46–58) · S(59–66). 랭크가 오를수록 경험치 배율도 오릅니다.
- **일일 퀘스트**: 본 퀘스트를 모두 채우면 클리어. 놓치면 다음 날 게으름 디버프(해제 퀘스트)가 붙습니다. 어제 기록은 오늘까지 고칠 수 있습니다.
- **여관(회복의 날)**: 4·11·18·…·60일째는 운동 대신 스트레칭·산책·수면이 퀘스트입니다.
- **피로도·디로드**: 피로도 4–5를 고르면 본 퀘스트 70%로 낮출 수 있습니다(경험치 절반, 연속 기록 유지).
- **보스**: 각 랭크 마지막 날 서브 퀘스트까지 다 하면 레이드 보스 처치 → 전리품, 테마·나만의 퀘스트 칸 해금. 놓쳐도 이후 서브 퀘스트까지 다 한 날 클리어됩니다.
- **부활의 깃털**: 7일 연속 클리어마다 1장. 실패한 날에 쓰면 연속 기록이 이어집니다.
- **상태창**: 레벨업마다 능력치 포인트 3개. 능력치 레이더(첫날 대비), 최근 7일 상승치, 최고 기록, 측정의 날 비교.
- **업적**: 해금되는 순간의 기록이 "증거"로 남습니다 (예: `팔굽혀펴기: Day 1 10회 → Day 23 30회`).
- **66일 이후**: 결산 화면에서 2회차(목표 +25%)를 레벨·업적을 이어서 시작할 수 있습니다.

## 🎮 RPG 요소
- **오늘의 숙제**: 매일 할 일. 끝내면 경험치와 **장비 1개 드랍**(일반·고급·희귀·영웅·전설·유물). 서브 퀘스트까지 올클하거나 본 퀘스트를 전부 150% 넘기면 등급이 오를 확률이 생김. 해금 탭 인벤토리에서 도감 수집.
- **전직**: Day 8에 전사·무도가·궁수·마법사·성직자 중 하나. 숙제를 끝낸 날마다 그 직업 능력치 +1. 상태창에서 바꿀 수 있음.
- **레이드**: 랭크 마지막 날 보스(작심삼일 슬라임 → 근육통 골렘 → 야식 마왕 → 이불 드래곤 → 숏폼 리치 → 귀차니즘 대마왕). 서브 퀘스트까지 올클하면 처치하고 전리품 획득.
- **여관**(회복의 날), **게으름 디버프**(놓친 다음 날 해제 퀘스트), **🧪 쉬엄쉬엄 모드**(피로도 높을 때 70%), **🪶 부활의 깃털**(연속 기록 복구).
- **협주**: 파티원과 같은 날 둘 다 숙제를 끝내면 +20 XP. 파티원에게 버프(💚 힐, 🛡️ 보호막, ⚔️ 공격력, 🧪 포션, ❤️ 고생했어)를 걸어 줄 수 있음.

## 👥 파티 (아내와 서로 진행 상황 보기)
각자 자기 휴대폰·자기 버전(남자/여자)으로 진행하면서, 파티 탭에서 서로의 **레벨·랭크·오늘 퀘스트 진행·66일 지도·능력치 레이더·최근 업적**을 실시간으로 봅니다.
- 파티원이 오늘 퀘스트를 클리어하면 알림이 뜨고, 상대 상태창에서 **버프**(🔥💪👏🛌❤️)을 보낼 수 있습니다.
- 파티 업적: 파티 결성, 함께 클리어(같은 날 둘 다 클리어) 1·7·30일, 응원 받기·보내기. 칭호 '듀오 큐', '평생 파티'.
- 기록 원본은 각자 휴대폰에 있고, 파티에는 요약만 올라갑니다.

가계부·여행 지도와 **같은 Firebase 프로젝트**를 씁니다(`level-up/firebase-config.js`). 처음 한 번만 Firestore 규칙에 파티 칸을 열어 주세요.

### 1. Firestore 규칙에 파티 추가 (PC에서 1분)
https://console.firebase.google.com → 여행 지도 프로젝트 → **Firestore Database → 규칙** 탭에서 아래처럼 `levelups` 칸을 더하고 **게시**
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /maps/{room} {
      allow read, write: if room.matches('^[a-z0-9]{20}$');
    }
    match /budgets/{room}/{rest=**} {
      allow read, write: if room.matches('^[a-z0-9]{20}$');
    }
    match /levelups/{room}/{rest=**} {
      allow read, write: if room.matches('^[a-z0-9]{20}$');
    }
  }
}
```
(빼먹으면 파티 탭에 "Firebase 규칙에 파티(levelups) 허용이 필요해요"라고 나옵니다.)

### 2. 파티 맺기
1. 내 휴대폰: **👥 파티 → 파티 만들기 → 초대 링크 보내기** (카톡 등으로 전송)
2. 아내: 링크를 열고 → 여자 버전으로 플레이어 등록 → 자동으로 파티 참여 → "홈 화면에 추가"
   - 이미 앱을 쓰고 있었다면 링크를 열면 "참여할까요?"가 뜹니다. 홈 화면 앱에서는 파티 탭에 링크(또는 20자리 코드)를 붙여 넣고 **참여**.
- 링크를 아는 사람은 누구나 파티원 진행 상황을 볼 수 있으니 가족·친구에게만 보내 주세요.

## 📲 다른 기기·아이폰 홈 화면 앱에서 이어하기
아이폰은 **사파리와 홈 화면 앱의 저장 공간이 따로**라서, 사파리에서 하다가 홈 화면에 추가하면 앱이 비어 있습니다.
1. 홈 화면 앱을 열면 맨 위 **📲 다른 곳에서 하던 캐릭터가 있나요?** 칸에 파티 초대 링크(또는 파티 탭의 20자리 코드)를 붙여 넣고 **찾기**
2. 목록에서 내 캐릭터를 고르면 레벨·기록·업적·장비가 그대로 넘어오고 파티에도 다시 연결됩니다.
- 그 뒤로는 파티를 통해 기기끼리 기록이 자동으로 맞춰집니다(마지막으로 직접 고친 쪽 기준). 두 기기에서 오프라인으로 동시에 고치면 나중에 올라간 쪽만 남으니 되도록 한 기기(홈 화면 앱)만 쓰세요.
- 이미 홈 화면 앱에서 새 캐릭터를 만들었어도 파티 탭(파티 없음 화면)의 같은 칸으로 바꿀 수 있습니다.

## 저장
기록은 브라우저(localStorage)에 저장하고, 파티에 들어가 있으면 진행 요약과 이어하기용 기록도 파티(Firebase)에 올라갑니다. 기기를 바꿀 땐 상태창 → 설정의 백업 내보내기/불러오기를 쓰세요.
